# MiniMax H3 · RTX 4070 笔记本一键部署包

把一张关键帧变成短视频，可再加一张末帧约束结束姿态。面向 **Windows 11 x64、RTX 4070 Laptop 8GB 显存、32GB 系统内存**。

本项目包含独立安装器、中文本地网页和 ComfyUI 工作流。普通用户按下面的双击入口操作即可；开发者也可以直接导入节点图。**不依赖扣子（Coze），无需其账号或 API Key。** 安装时联网下载组件和模型，生成任务在本机运行。

Powered by MiniMax H3.

[源码仓库](https://github.com/fiammettall/H3-4070-OneClick) · [部署包下载](https://github.com/fiammettall/H3-4070-OneClick/releases) · [自动测试结果](https://github.com/fiammettall/H3-4070-OneClick/actions/workflows/validate.yml)

**当前为待目标机验收的预览版。** 已做 CPU 逻辑与模拟接口检查，尚未在这台 4070 笔记本完成真实模型推理。安装完成表示文件和依赖就绪，生成效果与耗时需要首测确认。

想先了解流程，可读[原理与使用维护](docs/原理与使用维护.md)；项目现状见[GitHub 对标与成熟度评估](docs/GitHub对标与成熟度评估.md)，每次更新见[版本记录](CHANGELOG.md)。

## 使用说明：先做这三步

**第一次使用：[打开完整图文使用说明](docs/使用说明.md)**，从下载、安装到 56 帧首测逐步操作。

下载 [H3-4070-OneClick-v0.1.3-preview.zip](https://github.com/fiammettall/H3-4070-OneClick/releases/download/v0.1.3-preview/H3-4070-OneClick-v0.1.3-preview.zip)。发布页的 `Source code` 是开发者源码归档；普通用户请选择这个部署 ZIP。安装成功时窗口会显示“环境与模型就绪，等待目标4070首测”。

1. **解压到独立目录**，例如 `D:\AI\H3-4070`。使用本机 SSD，建议至少空闲 **60GB**，不要直接在压缩包内双击运行。
2. **双击 `1_安装或继续下载.cmd`**，等待环境安装、模型下载和 SHA-256 校验完成。首次需要联网；模型约 **21.79GB**，PyTorch 三件套压缩文件约 **1.93GB**，其他依赖约 **0.65GB**，另外还需缓存与解压空间。安装完成后不会自动生成视频。
3. **双击 `2_启动.cmd`**，在打开的页面上传首图，填动作提示词，再点击“生成这个镜头”。页面未自动打开时访问 <http://127.0.0.1:8195/>。第一次建议先选“约 2.33 秒 · 56 帧首测”。

无需预先安装 Python、Git 或 CUDA Toolkit。安装器会在本目录准备独立 Python 3.11.9，并安装锁定的源码、依赖和模型。**NVIDIA 驱动需要 r580 或更新版本**，本包不会自动安装驱动。生成前接通电源，并关闭暂时不用的游戏和其他占用显存的程序。

**安装中可以看见当前阶段和下载进度。** 大文件下载会定期显示百分比、已下载大小、总大小与速度；等待连接或暂时没有新数据也会提示。此时运行入口 3 会说明安装尚在进行，把后续步骤列为待完成；暂停、中断和失败会给出相应的继续操作。真实硬件问题仍会单独显示。

已使用旧包的用户按[保留下载进度升级](docs/使用说明.md#从旧版本升级并保留下载进度)更新原目录。v0.1.3 没有更换模型或 Python 依赖，校验通过的缓存可继续复用。

## 怎么做一个镜头

- 首图必填，末图可选；支持 PNG、JPG、WebP，单张不超过 16MB。图片比例尽量接近输出比例。
- 提示词描述这一小段的动作、镜头移动与希望保留的外观；用短镜头逐次调整，满意后再做下一个。
- 默认输出 **640×352、124 帧、24fps，约 5.17 秒**。首测可改为 56 帧，约 2.33 秒。随机种子留空会自动生成；记录种子便于比较修改。
- 结果在页面预览，也会保存到 `output`；上传图片在 `input`，任务记录在 `user\jobs`。

这里采用 H3 Lite Set A 兼容工作流的适配路线：W4A8 FL2VA、4B 量化编码器、ClipProj、Turbo LoRA 和原生音频。它用于关键帧生成视频，尚未配置原视频逐镜头换人。当前调度器为 **`res_multistep / simple`、4 个调度步**，不能将它等同于官方 Euler 配置的“4 次模型求值（4 NFE）”。

## 暂停、重试和查看错误

| 入口 | 用途 |
| --- | --- |
| `1_安装或继续下载.cmd` | 首次安装，或从保留的断点继续；同一时间只打开一个安装窗口。 |
| `2_启动.cmd` | 启动本包的生成服务和简易界面。 |
| `3_检查环境.cmd` | 查看硬件、驱动、依赖和模型检查结果。 |
| `4_停止服务.cmd` | 停止本包启动的服务；运行中的生成会中断。 |
| `5_暂停下载.cmd` | 请求暂停当前下载并保留断点，等待安装窗口显示已暂停。 |
| `6_修复安装.cmd` | 恢复锁定的程序与模型文件，复用可用缓存并保留备份；不删除用户输入和成片。 |

网络中断或下载报错后，保留现有目录，再双击入口 1。不要删掉 `.partial` 文件或 `.cache`；这些文件用于续传和复用下载。首次独立 Python 引导下载尚在运行时，暂停请求可能要等引导步骤结束后才生效。

报错时先查看 `logs` 中最新日志，以及 `_state\install_status.json`。把错误文字和对应日志一起保留；不要通过关闭 HTTPS 证书校验或随意替换依赖版本来绕过报错。页面一直显示等待服务时，先运行入口 3，再检查日志。缺少模型或环境未安装完成时，回到入口 1。

默认仅监听本机：简易界面 `127.0.0.1:8195`，ComfyUI `127.0.0.1:8194`。两台电脑各自运行独立镜头，不会合并显存。

页面提供任务历史、取消、原参数重试和输入复用。取消只针对本应用创建的任务。若提交结果不明确，页面会先查询原任务，避免误提交第二份；无法确认时请先检查队列与日志。修复前停止生成服务，安装器不会覆盖正在运行的环境。

## 版本与来源

固定版本与下载哈希在 `locks`。当前运行时为 Python 3.11.9、PyTorch 2.11.0 / torchvision 0.26.0 / torchaudio 2.11.0（CUDA 13.0）。这些版本的官方安装包已核验，目标 4070 上的完整推理仍待验收。

主模型保留来源仓库的真实文件名 `minimax_h3_fl2va_pruned_w4a8_mixed.safetensors`，来源为 AX1Y2JP。其尺寸与 H3 Lite 文档所列文件一致，但上游未公布原整合包对应哈希，**不能声称本包逐字节复现作者的百度网盘整合包**。

- 工作流参考：[Rimagination/h3lite](https://github.com/Rimagination/h3lite/tree/9bafafa6f1741fd6eb49d46b078e2dbb0feec3be)
- 推理引擎：[ComfyUI](https://github.com/Comfy-Org/ComfyUI/tree/72865f4f27eaf5396f8f36370e0a2be3a9a090ee)
- 主要节点：[ComfyUI-ClipProj](https://github.com/nicolab28/ComfyUI-ClipProj/tree/c01ba8fb8f41b4f2094dbd0b185cdc238fb6134c)
- 模型文件、修订号和 SHA-256：`locks\models.json`

分发包不含模型权重、动漫原片或原作角色图片；安装时从锁定来源下载模型。公开测试图的来源和许可见 `examples`。GitHub 仓库提供完整源码，Release 提供供普通用户拷贝的精简 ZIP；精简 ZIP 不含单元测试源码。软件、模型和素材分别适用各自的许可，详见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 和 `licenses`。
