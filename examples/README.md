# 可复现的公开输入示例

这两组示例用于验收安装、图片上传、首末帧约束、生成与导出通路。图片是本仓库脚本绘制的原创几何机器人场景，与 SVG 源文件一起按项目 MIT 许可证提供；没有使用私人 OP 原片、动漫角色或第三方示例视频。

当前只提供输入、提示词和工作流，**尚无 4070 实机生成成片或速度数据**。这类简单图形不能证明人物脸部、发型、服装一致性或复杂动漫镜头质量；目标机跑通后，应另外补充人物镜头样片和失败案例。

| 示例 | 输入 | 参数 | 用途 |
| --- | --- | --- | --- |
| `01-smoke-i2v` | 机器人首帧 | 640×352、56 帧、24 fps，约 2.33 秒 | 第一次完整生成，先检查通路 |
| `02-first-last` | 同一场景的首帧、举手末帧 | 640×352、124 帧、24 fps，约 5.17 秒 | 检查首末帧与持续动作 |

两组均固定种子 `40702026`，使用 `res_multistep`、`simple`、4 个调度步和强度 1.0 的配套 Turbo LoRA。4 个调度步不等于 4 次 Euler 模型求值。每组的 `config.json` 记录完整参数，`prompt.txt` 与工作流内提示词完全一致；`workflow.json` 为浏览器画布，`workflow.api.json` 为相同参数的 API 图。

## 在简易网页中使用

1. 完成安装并启动，打开项目简易网页。
2. 上传 `assets/h3_schoolyard_first.png`。使用 `02-first-last` 时，再上传 `assets/h3_schoolyard_last.png` 作为末帧。
3. 粘贴所选示例目录的 `prompt.txt` 全文；选 640×352、相应帧数，种子填 `40702026`。
4. 手动生成，检查完成后的预览、下载、任务参数和日志。

## 在 ComfyUI 画布中使用

1. 打开 `http://127.0.0.1:8194`，将所选示例的 `workflow.json` 拖入画布。
2. 在「首帧」节点中上传 `assets/h3_schoolyard_first.png`；首末帧示例还需在「末帧」节点上传 `assets/h3_schoolyard_last.png`。**导入 JSON 不会自动上传图片**，上传后确认节点选择的是实际图片文件名。
3. 模型组件应与安装器清单对应。确认图片、提示词、帧数和种子后，手动加入队列。
4. 文件保存在项目 `output/H3_4070/examples/` 下，画布的 SaveVideo 节点也会显示预览。

API 图同样需要先把图片上传到 ComfyUI，并将 LoadImage 的 `image` 值改为服务器返回的文件名。它不是自行上传文件的一键调用脚本。

## 维护与验收记录

在项目根目录运行以下命令，无需安装第三方 Python 包：

```text
python examples/build_examples.py --check
python scripts/validate_workflows.py
```

`--check` 只读检查 PNG、SVG、提示词、配置和工作流能否从生成器逐字节重建。修改示例设计后，执行 `python examples/build_examples.py` 可重新生成文件。PNG 使用固定图元、固定抗锯齿和未压缩 DEFLATE 块，避免字体或图像库版本改变资源。

`assets/manifest.json` 给出输入图片和 SVG 的大小、SHA-256 与来源。工作流校验会检查连接 ID、双向索引、槽位类型、控件顺序、模型锁和 API 图一致性；它不能替代真正的浏览器导入与 GPU 生成。

第一次 4070 实测后，请保存生成文件与网页中的任务记录，并记录驱动版本、耗时、峰值显存/系统内存、失败日志及观察到的变形。将结果标成「已验证」之前，至少完整跑过上述两组示例。即使锁定种子和参数，不同硬件、驱动或算子也不保证视频逐像素一致。
