# 使用说明：从下载到生成第一个镜头

适用于 **v0.1.2-preview、Windows 11 x64、RTX 4070 Laptop 8GB 显存、32GB 系统内存**。这是带中文网页的本地部署程序，内置 ComfyUI 工作流；不需要扣子（Coze）账号、API Key，也不用提前安装 Python、Git 或 CUDA Toolkit。

**目前是预览版，4070 实机生成尚待验证。** GitHub 的 CPU 与浏览器模拟检查已经通过；下面提供操作步骤，不承诺目标电脑的生成耗时或画面质量。

## 1. 下载哪个文件

打开 [v0.1.2-preview 下载页](https://github.com/fiammettall/H3-4070-OneClick/releases/tag/v0.1.2-preview)，找到页面下方的 **Assets**：

| 文件 | 用途 |
| --- | --- |
| [H3-4070-OneClick-v0.1.2-preview.zip](https://github.com/fiammettall/H3-4070-OneClick/releases/download/v0.1.2-preview/H3-4070-OneClick-v0.1.2-preview.zip) | 普通用户下载这个部署包。 |
| `H3-4070-OneClick-v0.1.2-preview.zip.sha256` | ZIP 的完整性校验值，需要核验下载文件时使用。 |
| `Source code (zip / tar.gz)` | 面向开发者的源码归档。初次使用请选上面的部署包。 |

部署 ZIP 只有约 194 KiB，里面是安装器、网页和工作流。首次安装会联网下载模型与运行环境，合计约 **24.4GB**；建议使用本机 SSD，至少空闲 **60GB**，给下载缓存、解压和输出留出空间。

## 2. 解压并安装

1. 将 ZIP **全部解压**到独立目录，例如 `D:\AI\H3-4070`。进入包含六个 `.cmd` 入口的文件夹，在这个文件夹中操作。
2. 接通笔记本电源。NVIDIA 驱动要求 r580 或更新版本；安装器会检查，本包不会安装显卡驱动。
3. 双击 **`1_安装或继续下载.cmd`**，等待独立 Python、固定依赖、节点和模型下载、安装并校验。首次耗时取决于网速。
4. 完整安装成功的标志是窗口出现 **“环境与模型就绪，等待目标4070首测”**。看到“源码准备完成”或单个模型完成时，仍需继续等待。

下载中断时保留原文件夹，再双击入口 1 即可续传。需要暂停时双击 `5_暂停下载.cmd`，等待安装窗口确认暂停；独立 Python 引导阶段的暂停可能延后生效。保留 `.partial` 文件和 `.cache` 缓存，它们用于续传。

## 3. 打开中文操作页面

安装成功后，双击 **`2_启动.cmd`**。启动器会打开浏览器：

**<http://127.0.0.1:8195/>**

如果浏览器没有自动打开，将这个地址复制到这台电脑的浏览器。等待页面显示 **“生成服务已连接”**。启动过程中不要重复双击多个启动窗口；仍连不上时运行 `3_检查环境.cmd`，并查看 `logs/comfy.log` 与 `logs/web.log`。

## 4. 照着示例生成第一条短片

先使用部署包自带的机器人图片和固定参数，方便比较两台电脑的运行结果。

![配套首帧输入：学校前的原创几何机器人](../examples/assets/h3_schoolyard_first.png)

| 页面上的项目 | 第一次怎么填 |
| --- | --- |
| **＋ 上传首图** | 选择 `examples/assets/h3_schoolyard_first.png`。 |
| 末图 | 先留空。 |
| **描述这个镜头的动作** | 用记事本打开 `examples/01-smoke-i2v/prompt.txt`，复制全文粘贴进提示词框。 |
| 尺寸 | 选择 **640 × 352 · 横向（默认）**。 |
| 时长 | 主动改成 **约 2.33 秒 · 56 帧首测**。界面初始默认是 124 帧。 |
| 种子 | 填 **40702026**。 |

确认首图已上传、服务已连接后，点击一次 **“生成这个镜头”**，等待页面更新进度。

完成后，在右侧播放预览，点击 **“保存视频 · 文件名”** 下载。简易页面生成的文件也会保存在部署目录的 **`output/H3_4070/`** 中；参数和实际工作流记录保存在 `user/jobs/`。

技术检查先看能否完整播放、是否黑屏或报错，再看机器人是否按提示举手。这个简单图形示例用于检查运行通路，人物脸部、头发和动漫画风需要另做样片验证。

## 5. 换成自己的图片与动作

第一条短片能正常生成、播放后，再尝试自己的单人物图片。支持 PNG、JPG、WebP，每张不超过 16MB，比例尽量接近输出比例。

先保留 56 帧，只换首图和提示词。例如：

> 固定镜头，中景。人物保持首图中的发型、服装和背景，轻轻转头看向镜头，眨一次眼。光照稳定，不切镜头。

需要限制结束姿态时，再添加外观一致的末图。可照 `examples/02-first-last/` 的首末帧示例操作，使用 `h3_schoolyard_first.png` 和 `h3_schoolyard_last.png`、124 帧和该目录的提示词。每次只增加一个变化，便于判断报错或画面变化的原因。

页面的 **“最近任务”** 可查看历史，使用 **“按原参数重试”** 或 **“复用输入并修改”**。需要停止单个生成时，点击 **“取消本任务”**。

## 6. 停止、续传和修复

| 双击入口 | 什么时候用 |
| --- | --- |
| `1_安装或继续下载.cmd` | 首次安装，或下载中断后继续。 |
| `2_启动.cmd` | 打开服务和中文页面。 |
| `3_检查环境.cmd` | 检查硬件、驱动、依赖、模型与运行状态。 |
| `4_停止服务.cmd` | 用完后退出本包；运行中的生成会被中断。 |
| `5_暂停下载.cmd` | 暂停下载并保留断点。 |
| `6_修复安装.cmd` | 恢复锁定的程序与模型文件；先使用入口 4 停止服务。 |

**只关闭浏览器，后台服务仍会运行。** 用完后双击入口 4。保留 `input/`、`output/` 和 `user/jobs/`，分别用于输入图、成片和任务记录。

## 7. 遇到问题先这样处理

| 现象 | 处理 |
| --- | --- |
| 下载报超时、断线 | 保留目录和临时文件，再运行入口 1；失败信息在 `logs/` 与 `_state/install_status.json`。 |
| 页面显示生成服务未连接 | 等待启动完成；仍失败则运行入口 3，查看 `logs/comfy.log`、`logs/web.log` 和端口占用报错。 |
| 显存不足、内存不足 | 保存其他工作，关闭暂时不用的游戏等程序；停止并重新启动本包，再用 56 帧试一次，保留报错。 |
| 缺模型、缺节点或校验失败 | 先完成入口 1；仍异常时停止服务后用入口 6 修复。 |
| 有视频，但人物变形或动作不对 | 保存该候选和参数，简化动作或换首图；文件生成成功与画面合格分别判断。 |

仍无法解决时，到 [Issues 提交问题](https://github.com/fiammettall/H3-4070-OneClick/issues/new/choose)，附出错阶段、错误文字、包版本、显卡、内存与相关日志片段。公开日志前删去个人信息；无需默认上传私人图片或原视频。

## 8. 需要查看 ComfyUI 节点时

普通使用在中文页面完成。需要调整工作流时，启动本包后打开 <http://127.0.0.1:8194/>，将 `workflows/h3lite_4070_i2v.json` 拖进画布；首测可以直接拖入 `examples/01-smoke-i2v/workflow.json`。

导入 JSON 后，仍要在「首帧」节点上传图片，再手动加入队列。详细节点说明见 [工作流说明](../workflows/README.md)，原理与日常维护见 [原理与使用维护](原理与使用维护.md)。
