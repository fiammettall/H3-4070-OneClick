# GitHub 工作流对标与成熟度评估

评估日期：2026-10-23。更新到 v0.1.2 预览包：补充画布工作流、公开输入示例及 GitHub 自动测试配置；目标 4070 实机测试等待包拷过去后进行。

结论：目前是具备安装器、固定组件和简易操作界面的内测项目。软件工程基础已建立，但目标 4070 上的完整安装、真实推理、画面质量与重复运行尚未验收。最主要的差距是可复现的运行证据。

## 到可推荐测试版还要完成什么

以下是给本项目建议的验收线，不是通用行业标准。

1. **完成一次全新安装到真实出片。** 在目标 4070 上从干净目录安装，不借用开发电脑的环境；先生成 56 帧，再生成 124 帧，确认视频可完整解码、尺寸帧率正确且画面有合理动作。
2. **固定样例并重复运行。** 至少准备三类镜头：单人物小动作、明显肢体动作、首末帧约束。建议累计不少于 10 次任务，覆盖冷启动和连续运行，保存成功与失败记录、耗时、资源峰值及成片。不要求所有随机画面都成为最终作品，但不能把黑屏、花屏或任务失败当成功。
3. **让新手按文档独立复现。** 从解压到看到成片，不需要开发者临时补命令。验证断网续传、取消任务、关闭后重开、重新安装修复，并保留用户素材和成片。
4. **完成公开交付验证。** 画布、输入示例、版本说明和 Windows 自动测试配置已准备；每次发行需检查对应提交的远程 CI 结果，后续还要补入真实输出和外部复现记录。把已实测的基线与实验加速设置分清楚。

第一项通过后才可以称为“本机跑通”；四项都有证据后，可以发布范围明确的测试版。稳定版还需要在一段实际使用中重复验证，并依据反馈修复问题。当前无法诚实地给出“已经完成 80%”或承诺还需几天，因为核心推理的兼容性和成片质量尚未测试。

## 适合本项目的定位

建议聚焦：**Windows 11 下，面向 RTX 4070 Laptop 8GB＋32GB 内存的 H3 首末帧短视频工作流与一键部署工具。**

这个范围的价值在于默认配置有实测、安装可恢复、人物镜头示例可复现、新手能操作和排错。多模型平台、复杂剪辑和大量加速插件都不必成为首版的条件。

当前流程可以理解为：准备人物关键帧 → 描述短动作 → 量化 H3 生成 → VAE 解码并保存 → 人工挑选后剪辑。量化主要减轻运行负担，Turbo 减少采样步骤；软件界面负责把这些步骤组织起来。要严格跟随原片动作，还需另行验证 Ref2VA 视频编辑，不能用首末帧生成的成功替代。

更通俗的操作与维护说明见[原理与使用维护](原理与使用维护.md)，真实数据填写位置见[目标机验收](目标机验收.md)。
