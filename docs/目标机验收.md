# RTX 4070 笔记本目标机验收

**当前状态：待实机。** 本文是一份可填写的验收记录，不是已完成的性能报告。现有 CPU、下载器、模拟接口和浏览器验证范围见 [VALIDATION.md](../VALIDATION.md)。

## 2. 按短片开始

1. 保存其他工作，关闭暂时不用的高显存程序，接通电源，完整运行安装与环境检查。
2. 先使用[公开示例](../examples/README.md)中的 56 帧候选，核对图片与参数并保持固定种子。通过后再准备一张外观清楚的单人物首图，动作限制为轻微转头或眨眼；人物素材测试独立记录。
3. 使用 `640×352`、56 帧、24fps、固定种子和默认 4 个调度步。保存实际提交参数及提示词，不在首测中同时改采样器或换模型。
4. 开始记录时间与资源占用，点击生成一次。失败则先保存日志和错误，停止扩大任务规模。
5. 若成功，完整播放视频，检查媒体与人物；再用同一输入做一次重复测试，区分首次加载与后续耗时。
6. 短片通过后，再分别尝试 124 帧和可选末图。每次只增加一个变化，独立记录结果。

不需要初学者修改节点来完成本表。真实默认配置为 `res_multistep / simple`、4 个调度步，不写成“Euler 4 NFE”。

资源可先通过 Windows 任务管理器观察：GPU 页记录独立与共享内存，内存页记录使用量与“已提交”。这类人工读数可能漏掉瞬时峰值，报告中要写清楚。需要按秒观察 NVIDIA 数据时，可以在终端运行以下只读命令，结束时按 Ctrl+C；部分笔记本字段可能返回 N/A。

```powershell
nvidia-smi --query-gpu=timestamp,name,driver_version,memory.total,memory.used,utilization.gpu,power.draw,power.limit --format=csv -l 1
```

对已保存成片计算哈希时，把示例路径改成自己的文件：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\output\H3_4070\实际成片.mp4'
```

## 4. 画面与动作验收

| 检查项 | 通过 / 不通过 / 未测，以及具体时间点 |
| --- | --- |
| 人物身份 | 脸、发色、发型、服装是否在整段中保持一致，有没有中途变成另一个人。 |
| 四肢与物体 | 手指、肢体、眼镜和道具是否增减、融化、穿插或丢失。 |
| 动作 | 要求的转头、眨眼等是否发生，幅度和方向是否合适。 |
| 镜头与背景 | 运镜是否符合描述，背景是否无故变形、漂移或跳变。 |
| 首末帧关系 | 起点是否接近首图；使用末图时结束姿态是否合理，过渡是否突兀。 |
| 连续性 | 是否明显闪烁、重复、冻结、突然切镜或姿态跳跃。 |
| OP 使用价值 | 哪个时间段可用、是否要裁切、是否要重试；与相邻镜头是否衔接。 |

“可以播放”属于技术通过；“人物和动作适合成片”属于视觉通过。二者都应给出自己的结论。FL2VA 首末帧生成仍不等于原片动作严格复刻。
